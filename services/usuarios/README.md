# Servicio de Usuarios

Registro, login y perfiles de los dos roles: **propietario** y **conductor**.

- Base de datos: `USUARIOS_DB`
- Puerto: `USUARIOS_PORT`
- Emite JWT para el resto de los servicios.

_Asignar._

## Endpoints previstos

- `POST /auth/register`
- `POST /auth/login`
- `GET /users/me`
