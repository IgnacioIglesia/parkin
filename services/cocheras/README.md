# Servicio de Cocheras

Alta, edición, ubicación, precio y disponibilidad de cada cochera publicada.

- Base de datos: `COCHERAS_DB`
- Puerto: `COCHERAS_PORT`
- La dirección exacta solo se expone a las partes de una reserva confirmada (confidencialidad).

## Endpoints previstos

- `GET /cocheras?zona=&desde=&hasta=`
- `PUT /cocheras/{id}`
